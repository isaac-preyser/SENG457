SENG 457 / 557 — Quantum Computing Cheat Sheet (Side 1)

1. Linear Algebra & Dirac Notation

  • Ket $|\psi\rangle$ = column vector; bra $\langle\psi| = |\psi\rangle^\dagger$ (conj. transpose).
  • Inner prod. $\langle\phi|\psi\rangle\in\mathbb{C}$; norm $\|\psi\|^2=\langle\psi|\psi\rangle$. Orthonormal: $\langle i|j\rangle=\delta_{ij}$.
  • Outer prod. $|\psi\rangle\langle\phi|$ is an operator (rank-1). $(AB)^\dagger=B^\dagger A^\dagger$.
  • Operator taxonomy. Normal: $AA^\dagger{=}A^\dagger A$ (⇔ diagonalizable by a unitary; orthonormal eigenbasis). Hermitian: $A{=}A^\dagger$ (normal + real $\lambda$). Unitary: $U^\dagger U{=}UU^\dagger{=}I$ (normal + $|\lambda|{=}1$, $U^{-1}{=}U^\dagger$). Roles: observables $\to$ Hermitian (real outcomes); gates / time-evolution $\to$ Unitary (preserve norm). Every Hermitian and every Unitary is Normal; not every Normal is H or U.
  • Tensor: $|a\rangle\otimes|b\rangle$, dim $2^n$ for $n$ qubits; $(A\otimes B)(C\otimes D)=AC\otimes BD$.

2. Single-Qubit States

  • $|0\rangle=\binom{1}{0}$, $|1\rangle=\binom{0}{1}$. State: $|\psi\rangle=\alpha|0\rangle+\beta|1\rangle$, $|\alpha|^2+|\beta|^2=1$.
  • Born rule (Z-basis): $P(0)=|\alpha|^2$, $P(1)=|\beta|^2$.
  • Bloch: $|\psi\rangle=\cos\tfrac{\theta}{2}|0\rangle+e^{i\phi}\sin\tfrac{\theta}{2}|1\rangle$. Global phase invisible; only relative phase matters.
  • Bases: |+⟩,|-⟩ = $\tfrac{1}{\sqrt2}(|0\rangle\pm|1\rangle)$ are X-eigenstates ($\pm1$); |+i⟩,|-i⟩ = $\tfrac{1}{\sqrt2}(|0\rangle\pm i|1\rangle)$ are Y-eigenstates.
  • Expectation of observable $A$: $\langle A\rangle=\langle\psi|A|\psi\rangle$ (real if $A$ Hermitian).
  • Projective measurement, projectors $P_k$, $\sum P_k=I$: prob $\langle\psi|P_k|\psi\rangle$, post-state $P_k|\psi\rangle/\sqrt{\langle\psi|P_k|\psi\rangle}$.

4. Multi-Qubit Systems & 2-Qubit Gates

  • Order $|00\rangle,|01\rangle,|10\rangle,|11\rangle$ ↔ vectors $e_0,e_1,e_2,e_3\in\mathbb{C}^4$.
  • CNOT$_{c\to t}$: flips $t$ iff $c=1$. $|10\rangle\!\leftrightarrow\!|11\rangle$. $\mathrm{CNOT}=|0\rangle\langle0|\otimes I+|1\rangle\langle1|\otimes X$.
  • CZ$=\mathrm{diag}(1,1,1,-1)$. CNOT $=(I\otimes H)\,\mathrm{CZ}\,(I\otimes H)$.
  • SWAP: 3 CNOTs $=\mathrm{CX}_{12}\mathrm{CX}_{21}\mathrm{CX}_{12}$.
  • Toffoli (CCX): flip target iff both controls $=|1\rangle$. Fredkin (CSWAP): SWAP iff control $=|1\rangle$.
  • Multi-controlled $Z$: $C^{n-1}Z=H_t\cdot \mathrm{MCX}\cdot H_t$.

5. Bell States, Entanglement, No-Cloning

$|\Phi^\pm\rangle=\tfrac{1}{\sqrt2}(|00\rangle\pm|11\rangle)$, $|\Psi^\pm\rangle=\tfrac{1}{\sqrt2}(|01\rangle\pm|10\rangle)$.
  • Prepare $|\Phi^+\rangle$: $H$ on q0, then CNOT(q0→q1) starting from $|00\rangle$.
  • Bell measurement: CNOT(q0→q1), then $H$ on q0, measure both (inverse of prep).
  • State $|\psi\rangle$ separable ⇔ $|\psi\rangle=|a\rangle\otimes|b\rangle$ (Schmidt rank 1). Bell states are maximally entangled (Schmidt rank 2, equal coeffs).
  • Schmidt decomposition: any bipartite $|\psi\rangle_{AB}=\!\sum_{k=1}^{r}\lambda_k|u_k\rangle_A|v_k\rangle_B$, $\lambda_k>0$, $\sum\lambda_k^2=1$, with $\{|u_k\rangle\},\{|v_k\rangle\}$ orthonormal. Rank $r$ is basis-invariant: $r{=}1\Leftrightarrow$ separable, $r>1\Leftrightarrow$ entangled. Gives reduced-state diagonalization for free.
  • Entanglement vs classical correlation: classical = pre-assigned hidden outcomes (red/blue envelopes). Entanglement = joint state has no product form; correlations appear in every measurement basis, not just one. This is why Bell / CHSH inequalities are violated.
  • No-cloning: No unitary $U$ with $U(|\psi\rangle|0\rangle)=|\psi\rangle|\psi\rangle$ for arbitrary $|\psi\rangle$. Proof sketch: $\langle\psi|\psi'\rangle^2=\langle\psi|\psi'\rangle\Rightarrow$ overlap is 0 or 1.
Pauli expectations on Bell states (act-and-read: $X_0X_1|\Phi^+\rangle=|\Phi^+\rangle$, $Y_0Y_1|\Phi^+\rangle=-|\Phi^+\rangle$, $Z_0Z_1|\Phi^+\rangle=|\Phi^+\rangle$):
$\langle X_0X_1\rangle$$\langle Y_0Y_1\rangle$$\langle Z_0Z_1\rangle$
$|\Phi^+\rangle$$+1$$-1$$+1$
$|\Phi^-\rangle$$-1$$+1$$+1$
$|\Psi^+\rangle$$+1$$+1$$-1$
$|\Psi^-\rangle$$-1$$-1$$-1$
Sum $X_0X_1{+}Y_0Y_1{+}Z_0Z_1$: $\Phi^+\!\to\!+1$, $\Phi^-\!\to\!+1$, $\Psi^+\!\to\!+1$, $\Psi^-\!\to\!-3$ (Heisenberg / singlet benchmark).

Teleportation: Alice has unknown $|\psi\rangle$, shares $|\Phi^+\rangle$ with Bob.

  1. CNOT(psi→Alice's half), then $H$ on psi.
  2. Measure both Alice qubits → bits $(m_1,m_2)$.
  3. Bob applies $X^{m_2}Z^{m_1}$ on his qubit ⇒ gets $|\psi\rangle$.

7. Oracles & Phase Kickback

  • Bit oracle: $U_f|x\rangle|y\rangle=|x\rangle|y\oplus f(x)\rangle$ (reversible).
  • Phase oracle: $U_f^\mathrm{ph}|x\rangle=(-1)^{f(x)}|x\rangle$.
Phase kickback (set ancilla to $|-\rangle$): $$U_f\bigl(|x\rangle\otimes|-\rangle\bigr)=(-1)^{f(x)}|x\rangle\otimes|-\rangle.$$
Universal Hadamard identity: $$H^{\otimes n}|x\rangle=\frac{1}{\sqrt{2^n}}\sum_{y\in\{0,1\}^n}(-1)^{x\cdot y}|y\rangle.$$

Course "four-step" template: (1) Init + ancilla $|-\rangle$. (2) Mix: $H^{\otimes n}$. (3) Encode: oracle. (4) Mix/decode: $H^{\otimes n}$ or QFT$^{-1}$. (5) Measure in computational basis.

8. Deutsch · Deutsch–Jozsa · Bernstein–Vazirani

  • Deutsch ($n=1$): $f:\{0,1\}\!\to\!\{0,1\}$. After H⊗H, $U_f$, then $H\otimes I$ → measure q0: 0⇔constant, 1⇔balanced. 1 query vs 2 classical.
  • Deutsch–Jozsa: promise $f$ constant or balanced. Amplitude on $|0\rangle^{\otimes n}$ after $H^{\otimes n}U_f H^{\otimes n}$: $\frac{1}{2^n}\!\sum_x (-1)^{f(x)}=\pm1$ (const) or $0$ (bal). 1 query vs $2^{n-1}{+}1$ classical worst-case.
  • Bernstein–Vazirani: $f(x)=s\cdot x\bmod 2$. Algorithm: $|0\rangle^{\otimes n}|1\rangle\!\to\! H^{\otimes n}\!\otimes\! H \!\to\! U_f\!\to\! H^{\otimes n}$ on data → measure $\Rightarrow|s\rangle$ w.p. 1. 1 query vs $n$ classical.

9. Grover’s Search

  • $N=2^n$ items, $M$ marked. Phase oracle $U_f|x\rangle=(-1)^{f(x)}|x\rangle$.
  • Diffusion: $D=2|s\rangle\langle s|-I = H^{\otimes n}(2|0^n\rangle\langle 0^n|-I)H^{\otimes n}$, with $|s\rangle=H^{\otimes n}|0^n\rangle$.
  • Iteration $G=D\,U_f$. Geometric: 2-D plane (good $|\alpha\rangle$ / bad $|\beta\rangle$); $G$ rotates by $2\theta$, $\sin\theta=\sqrt{M/N}$.
Success prob.: $P_{\text{good}}(k)=\sin^2\!\bigl((2k{+}1)\theta\bigr)$.
Optimal: $k^*\approx \dfrac{\pi}{4}\sqrt{\dfrac{N}{M}}-\tfrac12$.
$M{=}1$, large $N$: $k^*\!\approx\!\tfrac{\pi}{4}\sqrt{N}$ ⇒ $O(\sqrt N)$ queries (quadratic speedup).
  • Phase oracle for marked string $s$: X on bits where $s_i=0$, multi-controlled $Z$, undo Xs.
  • Over-rotation: $P_{\text{good}}$ oscillates — do not overshoot $k^*$.
  • Tiny check ($n=2$, $M=1$): $\theta=\pi/6$, 1 iteration ⇒ $P=\sin^2(\pi/2)=1$.
  • Amplitude amplification: $Q=-A\,S_0\,A^{-1}\,S_\chi$ (Grover is $A=H^{\otimes n}$).

10. Eigenstructure & Spectral Decomposition

  • $A|v\rangle=\lambda|v\rangle$. Hermitian $A$: $\lambda\in\mathbb{R}$, distinct-$\lambda$ eigvecs orthogonal.
  • Spectral theorem: every normal $A$ has $A{=}\sum_k \lambda_k|v_k\rangle\langle v_k|$ with $\{|v_k\rangle\}$ orthonormal ($A{=}UDU^\dagger$). Measurement: projectors $P_k{=}|v_k\rangle\langle v_k|$, readings $\lambda_k$, $\langle A\rangle{=}\sum\lambda_k|c_k|^2$.
  • Functions of $A$: $f(A)=\sum_k f(\lambda_k)|v_k\rangle\langle v_k|$.
  • Unitary spectrum: $|\lambda|=1$, $\lambda=e^{i2\pi\varphi}$, phase $\varphi\in[0,1)$.
2×2 eigenvalues (mean–product trick). For any $2{\times}2$ $A$, char. poly. is $\lambda^2-\tau\lambda+\Delta=0$ with $\tau{=}\mathrm{tr}\,A$, $\Delta{=}\det A$. Let $m{=}\tau/2$ (mean), $p{=}\Delta$ (product): $$\lambda_{\pm}=m\pm\sqrt{m^{2}-p},\qquad \lambda_1+\lambda_2=\tau,\;\;\lambda_1\lambda_2=\Delta.$$ Eigenvector for $\lambda$: solve $(A-\lambda I)v=0$ (pick any non-zero row).
Example. $A=X+Z=\bigl[\begin{smallmatrix}1&1\\1&-1\end{smallmatrix}\bigr]$: $\tau{=}0$, $\Delta{=}-2$ ⇒ $m{=}0$, $p{=}-2$ ⇒ $\lambda_\pm=\pm\sqrt{2}$. Check: $\lambda_++\lambda_-=0=\tau$✓, $\lambda_+\lambda_-=-2=\Delta$✓.

11. Matrix Exponentials & Hamiltonian Simulation

  • $e^M=\sum_n M^n/n!$. If $A^2{=}I$: $e^{i\theta A}=\cos\theta\,I+i\sin\theta\,A$.
  • $[A,B]=0\Rightarrow e^{A+B}=e^A e^B$. Otherwise Trotter: $e^{-i(A+B)t}\approx (e^{-iAt/r}e^{-iBt/r})^r$.
  • If $H=UDU^\dagger$ ($D$ diagonal): $e^{-iHt}=U\,e^{-iDt}\,U^\dagger$.
  • Diagonalize Pauli strings to $Z$-strings via Cliffords: $H X H{=}Z$, $S X S^\dagger{=}Y$, then apply $e^{-i\theta Z\otimes\cdots\otimes Z}$.
  • QPE bridge: $U|u\rangle=e^{i2\pi\varphi}|u\rangle$, estimate $\varphi$.

12. Quantum Fourier Transform (QFT)

Definition ($N=2^n$): $\;\mathrm{QFT}|j\rangle=\dfrac{1}{\sqrt N}\displaystyle\sum_{k=0}^{N-1}e^{2\pi i jk/N}|k\rangle$.
Product (binary-fraction) form: $$\begin{aligned} \mathrm{QFT}\,&|j_1\dots j_n\rangle =\\ &\tfrac{1}{\sqrt{2^n}}\!\bigotimes_{l=1}^{n}\!\Bigl(|0\rangle+e^{2\pi i\,0.j_l\dots j_n}|1\rangle\Bigr). \end{aligned}$$ $0.j_l\dots = j_l/2 + j_{l+1}/4 + \dots$ (binary fraction).
  • Circuit recipe: on each qubit apply $H$, then controlled phase $R_m=\mathrm{diag}(1,e^{2\pi i/2^m})$ from later qubits; finish with SWAPs to reverse qubit order.
  • Cost: $O(n^2)$ gates (vs classical FFT $O(N\log N)$).
  • Inverse QFT (used in QPE): reverse all gates and conjugate phases ($R_m\to R_m^\dagger$).
  • QFT diagonalizes the cyclic shift; computational basis ↔ Fourier (relative-phase) basis.
  • 1-qubit Fourier basis: $\mathrm{QFT}_2=H$, so the Fourier basis is the X-basis $\{|+\rangle,|-\rangle\}$. Identity used on quizzes: $\tfrac{1}{\sqrt2}(|+\rangle+|-\rangle)=|0\rangle$, $\tfrac{1}{\sqrt2}(|+\rangle-|-\rangle)=|1\rangle$.

13. Quantum Phase Estimation (QPE)

Problem: given $U$ and eigenstate $|u\rangle$ with $U|u\rangle=e^{2\pi i\varphi}|u\rangle$, estimate $\varphi\in[0,1)$.

Recipe (m counting qubits):
  1. Init: $|0\rangle^{\otimes m}\otimes|u\rangle$, then $H^{\otimes m}$ on counters.
  2. Apply controlled-$U^{2^k}$ from counter $k$ onto $|u\rangle$.
  3. State $\to \tfrac{1}{\sqrt{2^m}}\!\sum_k e^{2\pi i\varphi k}|k\rangle\!\otimes\!|u\rangle$.
  4. Apply $\mathrm{QFT}^{-1}$ on counters; measure → integer $a$.
  • Exact: if $\varphi=a/2^m$, get $a$ with prob 1 ⇒ $\varphi=a/2^m$.
  • Approx: nearest $m$-bit estimate has prob $\ge 4/\pi^2\approx 0.405$.
  • Resources for accuracy $\varepsilon$, prob $\ge 1{-}\delta$: $m=\lceil\log_2(1/\varepsilon)\rceil+\lceil\log_2(2+1/(2\delta))\rceil$.
  • Canonical example: $U=T$ on $|1\rangle$ has $\varphi=1/8$; $U=R_z(2\pi\varphi)$ on $|1\rangle$ generalizes.
  • Endianness: in PennyLane, controlled-$U^{2^0}$ on the last estimation wire and $U^{2^{m-1}}$ on the first; in Qiskit, mind whether q0 = MSB or LSB of the readout integer.
  • Applications: order finding (Shor), eigen-energy estimation (chemistry/VQE), HHL.
QPE → ground-state energy. Choose $U=e^{-iHt}$. If $H|u\rangle=E|u\rangle$ then $U|u\rangle=e^{-iEt}|u\rangle=e^{2\pi i\varphi}|u\rangle$, so $\boxed{\,E=-\dfrac{2\pi\,\varphi}{t}\;(\bmod\,2\pi/t)}$. Run QPE on state $|u\rangle$ (or a guess close to ground) to read $\varphi$ → pick the lowest $E$.
HHL one-liner. Solves linear system $A\mathbf{x}{=}\mathbf{b}$ using QPE on $e^{iAt}$ + controlled rotation + uncompute. Does NOT factor integers; does NOT use Grover.

14. Combinatorial Optimization & QAOA

  • Encoding: $x_i\in\{0,1\}\leftrightarrow s_i=1{-}2x_i\in\{\pm1\}$, $s_i\to Z_i$. Cost $C(z)\to H_C=\sum_z C(z)|z\rangle\langle z|$ (diagonal).
  • Constraints folded in as penalty terms in QUBO.
MaxCut Hamiltonian (graph $G=(V,E)$, maximize):
$$H_C=\tfrac{1}{2}\sum_{(i,j)\in E}(I-Z_iZ_j).$$
QAOA ansatz ($p$ layers, X-mixer): $$\begin{aligned} |\psi(\boldsymbol\gamma,\boldsymbol\beta)\rangle =\;&\!\prod_{k=1}^{p}\! e^{-i\beta_k H_M} e^{-i\gamma_k H_C}\\[-1pt] &\cdot\,H^{\otimes n}|0\rangle^{\otimes n},\\ H_M=\;&\sum_i X_i. \end{aligned}$$
  • Implement $e^{-i\gamma Z_iZ_j}=\mathrm{CNOT}_{ij}\,R_z(2\gamma)_j\,\mathrm{CNOT}_{ij}$.
  • Implement $e^{-i\beta X_i}=R_x(2\beta)_i$.
  • Outer loop: classical optimizer minimizes $\langle\psi|H_C|\psi\rangle$ over $2p$ angles.
  • $p\!\to\!\infty$ limit: Trotterized adiabatic interpolation $H(s)=(1{-}s)H_M+sH_C$ ⇒ recovers ground state of $H_C$.
  • Sampling: measurement in $Z$ gives bitstring $z$ w.p. $|\langle z|\psi\rangle|^2$; report best observed $C(z)$.
  • QAOA vs VQE: QAOA = problem-structured, $2p$ params; VQE = generic ansatz, many params (chemistry/ground states).

14b. Common QUBO / Ising Encodings

Spin↔binary: $x_i=\tfrac{1-s_i}{2}\in\{0,1\}$, $s_i=1{-}2x_i\in\{\pm1\}$, $s_i\!\to\!Z_i$.
Useful identities: $x_i^2=x_i$ (idempotent), $s_i^2=1$, $Z_i^2=I$. Products: $x_i x_j=\tfrac14(1-s_i)(1-s_j)$; so $s_i s_j \!\to\! Z_iZ_j$ and any quadratic binary form becomes $\sum c_{ij} Z_iZ_j+\sum c_i Z_i+\text{const}$.
Equality constraint "choose exactly $K$ items" $\Sigma_i x_i=K$: add penalty $\lambda\bigl(\sum_i x_i-K\bigr)^2$ (tune $\lambda$ larger than any cost gap).
Inequality via slack bits $y_k$: $\sum x_i\le K \Rightarrow \sum x_i+\sum y_k=K$ with slack added to penalty.
  • MaxCut: $H_C=\tfrac12\!\sum_{(i,j)\in E}(I{-}Z_iZ_j)$; $+1$ per cut edge.
  • Number partition: $H=(\sum_i a_i s_i)^2$. Ground energy $0$ iff perfect split exists.
  • Max independent set: $H=-\!\sum x_i+A\!\sum_{(i,j)\in E}x_ix_j$, $A{>}1$. Vertex cover: $H=\sum x_i+A\!\sum_{(i,j)\in E}(1{-}x_i)(1{-}x_j)$.
  • $K$-coloring: one-hot $x_{v,k}$, penalize non-one-hot + same-colour adjacent edges.

15. Problem-Solving Toolkit

  • $\langle A\rangle$: expand $|\psi\rangle$ in $A$’s eigenbasis, $\langle A\rangle=\sum_k \lambda_k|c_k|^2$.
  • 1-qubit VQE ids: $R_X(\theta)|0\rangle$ ⇒ $\langle Z\rangle{=}\cos\theta,\langle X\rangle{=}0,\langle Y\rangle{=}-\sin\theta$; $R_Y(\theta)|0\rangle$ ⇒ $\langle Z\rangle{=}\cos\theta,\langle X\rangle{=}\sin\theta,\langle Y\rangle{=}0$.
  • Entangled? 2-qubit $a|00\rangle{+}b|01\rangle{+}c|10\rangle{+}d|11\rangle$ separable ⇔ $ad{=}bc$.
  • Grover $k$: $\theta{=}\arcsin\!\sqrt{M/N}$, $k{=}\lfloor\pi/(4\theta)\rfloor$. QPE precision: $m$ bits resolve $\varphi$ to $1/2^m$.

W6. Complexity Summary

Queries/gates (classical → quantum): Deutsch $2\!\to\!1$; DJ $2^{n-1}{+}1\!\to\!1$; BV $n\!\to\!1$; Grover $O(N/M)\!\to\!O(\sqrt{N/M})$; Shor $e^{n^{1/3}}\!\to\!O(n^3)$; QFT $O(N\log N)\!\to\!O(n^2)$.

W7. Concept Bank (written answers)

Born rule. $P(k){=}|\langle k|\psi\rangle|^2$: the bridge from amplitudes (what gates manipulate) to probabilities (what we observe).
Interference. Amplitudes combine as complex waves before squaring. Constructive: paths add → answer amplified; destructive: paths cancel → wrong answers killed. Only relative phase matters.
Phase eng. vs interference eng. Phase eng. = shape relative phases (oracle $(-1)^{f(x)}$, $R_z$, $C\!R_k$). Interference eng. = design how they recombine ($H^{\otimes n}$, QFT, diffusion). Control phase $\Rightarrow$ control interference $\Rightarrow$ control measurement.
Why superposition alone $\ne$ speedup. Measurement returns one basis state. Speedup needs all four: superposition + phase eng. + interference + problem structure (period, marked set, eigenvalue).
Grover is quadratic. Iteration rotates by $2\theta$ in a 2-D subspace, $\theta\!\sim\!\sqrt{M/N}$, so $\sim\!\sqrt{N/M}$ iterations. No phase structure ⇒ no log speedup.
QPE primitive. Extracts $\varphi$ from $U|u\rangle{=}e^{2\pi i\varphi}|u\rangle$. Used in Shor (period), chemistry/VQE-verify ($U{=}e^{-iHt}$), HHL (eigenvalue inversion).
Teleportation / no-FTL. Resources: 1 Bell pair + 2 cbits. Bob's qubit is random until the 2 cbits arrive (classical channel $\le c$) $\Rightarrow$ no superluminal signalling, no cloning.

PennyLane — QNode, expval, Hamiltonian

import pennylane as qml
from pennylane import numpy as np
dev = qml.device("default.qubit", wires=2)
H = qml.Hamiltonian([1,1,1],
    [qml.PauliX(0)@qml.PauliX(1),
     qml.PauliY(0)@qml.PauliY(1),
     qml.PauliZ(0)@qml.PauliZ(1)])
@qml.qnode(dev)
def bell_energy():
    qml.Hadamard(0); qml.CNOT(wires=[0,1])
    return qml.expval(H)     # or qml.probs(), qml.state()
